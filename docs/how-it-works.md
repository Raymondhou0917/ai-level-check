# 它會讀什麼、產出什麼

本機 skill 只在**你的電腦**上跑。原始對話不會上傳到這個 GitHub 專案，也不會送到雷蒙或任何中央伺服器。

你如果本來就用雲端 LLM（ChatGPT、Claude、Gemini），對話本來就會經過那家的雲端。這套工具不會多開一條路，把資料送到作者這邊。

```
  你的電腦（紀錄本來就在這裡）
  ┌────────────────────────────────────────┐
  │  ~/.claude/projects/*.jsonl            │
  │  ~/.codex/sessions/**/*.jsonl          │
  │  ~/.gemini/antigravity/**/*.db（有才掃）│
  └───────────────┬────────────────────────┘
                  │  collect.py（純本機，不連網、不上傳）
                  ▼
  ┌────────────────────────────────────────┐
  │  證據包 evidence/                       │
  │  ├ summary.json  可核對的發生次數        │
  │  ├ metrics.md    人類可讀版             │
  │  └ cases.md      抽樣案例＋原句摘錄      │
  └───────────────┬────────────────────────┘
                  │  你自己的 AI 讀證據包 ＋ references/ 的判準
                  ▼
  ┌────────────────────────────────────────┐
  │  報告書（單檔 HTML）                     │
  │  ├ 總覽頁    等級／驗證狀態／分型／摘要    │
  │  └ 詳細分析  六節，每個判斷都指得出案例    │
  └───────────────┬────────────────────────┘
                  │  publish.sh（團隊模式，本人確認後才推）
                  ▼
  ┌────────────────────────────────────────┐
  │  公司 private repo                      │
  │  git 歷史 = 存證，推上去就改不掉          │
  └────────────────────────────────────────┘
```

三個刻意的設計：

- **原始紀錄不離開本機。** 上傳的只有你自己決定要推的報告，`evidence/` 在 `.gitignore` 裡。
- **每個人自己跑、自己決定推不推。** 沒有中央掃描，主管拿不到別人的原始對話。
- **推上去就刪不掉。** 報告不能事後修飾，這是它有公信力的來源。

貼上模式評的是你貼上的對話，或這一則網頁 Chat 裡已經有的內容。同樣不會經過這個專案的伺服器。Prompt 會叫模型去讀公開 GitHub，只讀判準與版型，不上傳你的紀錄。
